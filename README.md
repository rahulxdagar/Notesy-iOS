# Notesy (iOS)

Notesy is an iOS notes application project.

## Overview

This repository is intended to host the iOS implementation of Notesy, including app code, assets, and tests.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/rahulxdagar/Notesy---iOS.git
   cd Notesy---iOS
   ```
2. Open the project in Xcode.
3. Select an iOS simulator (or connected device) and run the app.

## Development

- Use Xcode for day-to-day development.
- Keep changes focused and documented.
- Add/update tests alongside feature changes when test targets are present.
